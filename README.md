# OneBox Windows

OneBox 是本机多邮箱客户端。当前源码实现了WPF列表与独立阅读页、Gmail/QQ/网易的IMAP/SMTP、旧Gmail账号的OAuth/Gmail API、本地 SQLite 缓存和 Windows 凭据管理器。目标框架为 .NET 8，SDK 锁定为 8.0.417。当前机器上的 .NET 10 运行时在程序启动前发生内部错误，因此交付版本使用 .NET 8 自包含发布。

## 开发环境

- Windows 10/11、.NET 8 SDK 8.0.417。
- 邮件正文的 HTML 阅读需要 WebView2 Runtime；纯文本可直接显示。
- Gmail添加账号时填写邮箱地址和16位应用专用密码，不需要创建Google Cloud项目或导入JSON。先开启Google账号的两步验证，再在[应用专用密码](https://myaccount.google.com/apppasswords)页面生成密码；不能填写Google登录密码。支持gmail.com和googlemail.com；部分组织账号或启用高级保护的账号可能无法生成应用专用密码。使用imap.gmail.com:993和smtp.gmail.com:465，均启用SSL/TLS。Google修改账号密码后会撤销应用专用密码，此时选择账号并点击“重新授权”，填写新生成的应用专用密码。
- 已有OAuth方式接入的Gmail账号保留原授权和缓存，不自动切换到IMAP。需要改用应用专用密码时，可移除旧账号后重新添加；移除会清除该账号本机缓存和待同步操作，不删除服务器邮件。
- QQ 和网易邮箱需要先在网页端开启 IMAP/SMTP，添加时输入客户端授权码，而不是登录密码。网易首批支持 `163.com`、`126.com`、`yeah.net`。
- 在侧栏“设置→网络代理”选择使用系统代理、不使用代理或自定义代理，默认使用系统代理；自定义支持HTTP、HTTPS和SOCKS5地址，填写后点击“应用代理”。代理设置保存在EXE同目录的`reader-settings.json`，对后续邮箱收发、同步和连接验证生效；系统未设置代理时直接连接。自定义地址不支持内嵌账号密码。
- 添加账号和更新授权时，对话框保留并显示连接验证进度，验证期间禁止重复点击，支持取消。收信、发信的连接及认证各最多等待15秒，失败后在对话框分别显示原因，可修改密码后重试；两项验证成功才保存凭据和账号。

账号令牌、授权码、应用专用密码和Google客户端密钥保存到Windows凭据管理器。账号、邮件、同步游标和待同步操作保存到EXE同目录的`mail.db`。旧版OAuth账号的Gmail客户端ID是非秘密元数据，保存到同目录的`google-client-id.txt`；导入的JSON不会被复制。WebView2用户数据也放在EXE同目录的`WebView2`文件夹。数据库升级时先在同目录生成带时间戳的备份。仓库不存放实际账号凭据。

自动同步按账号记录时间，启动时先读取本地缓存，距离上次同步满2小时才拉取邮件；没有同步记录的账号进行首次同步。网络失败后每5分钟额外重试一次，最多3次，耗尽后等待距最后一次尝试满2小时的新一轮同步；授权失效不自动重试。时间与重试次数保存到EXE同目录的`sync-schedule.json`，重启继续沿用；首次升级时沿用数据库中上次成功同步时间。程序每15秒检查是否到期，手动同步不受间隔限制。

旧版Gmail OAuth授权会申请离线访问，刷新令牌在 Windows 凭据管理器中跨重启保留，短期访问令牌到期后自动续期。Google 仍可在用户撤销授权、客户端设置改变等情况下使其失效。若 OAuth 同意屏幕保持 **External / Testing**，Gmail 权限对应的测试授权和刷新令牌约 7 天后会过期；长期自用应核对项目发布状态，不能承诺令牌永远有效。

## 当前功能

- 统一收件箱、按账号收件箱、最近90天邮件索引、正文按需获取、本地搜索（中文、完整拼音、首字母）、手动刷新和运行期间轮询。
- 全宽邮件列表区分未读与已读；打开后进入独立阅读页，提供返回、上一封和下一封。正文打开后自动标记已读，保留标为未读操作；状态先保存到本地队列，再同步服务器。
- 旧版Gmail OAuth账号刷新令牌续期与 `historyId` 增量读取；IMAP 按 `UIDVALIDITY` 检测重建，增量获取新邮件并核对最近邮件的 FLAGS。
- 纯文本及受限WebView2 HTML阅读。远程图片默认自动加载，可在侧栏“设置”中关闭；关闭后可对单封邮件点击“显示远程图片”。选择保存到EXE同目录的`reader-settings.json`。脚本和其他远程资源仍被阻止。
- 邮件时间按本机时区显示；顶部日志栏固定展示最新一条，悬停或点击右侧箭头查看最近20条历史日志。
- 选中邮件正文或文本框中的文字后自动复制到剪贴板，默认开启；可在“设置→邮件阅读与下载→选中文本后自动复制”关闭，立即生效并保存到本机。HTML正文仅在软件处于前台、松开鼠标后读取选区，邮件脚本仍保持禁用。
- 正文内嵌图片（cid）自动解析并缓存到EXE同目录的`InlineImages`，不受远程图片开关影响；旧版缺图缓存再次打开时会重新解析。阅读工具栏提供“保存内嵌图片”，右键内嵌图片也可选择“保存图片”，复用附件下载位置。同一图片在同一目录已保存且内容一致时不重复写入，删除后可以重新保存。
- 撰写、发信账号确认、附件发送和手动下载；下载使用安全文件名且不覆盖现有文件。可在侧栏“设置→附件下载位置”指定默认目录，重启后保留；未设置时每次选择保存位置。
- 已读/未读和星标操作先写本地待执行队列，连接恢复后回写服务端；单账号失败不会阻断其他账号。
- 侧栏“收藏夹”集中查看所有账号已同步的星标邮件，支持本地搜索和阅读；取消收藏后从收藏夹移除，收件箱中的原邮件保留。
- 列表右侧星标可直接点击；附件下载中禁止重复触发，进度和结果在顶部消息区展示。搜索框靠左，消息区按成功、失败、告警分色，每5秒轮播，悬停暂停并查看最近20条，也可手动切换。
- 支持GB2312、GBK、GB18030和Big5正文编码，旧的相关正文缓存再次打开时重新拉取。
- 账号独立移除及重新授权。移除只清除本机数据与凭据，不删除服务器邮件。
- 最大化启动；关闭隐藏托盘、最小化留在任务栏，托盘左键切换窗口，右键仅显示与退出。

## 尚待验收与完善

真实 Gmail、QQ、网易账号尚未接入验证；程序未启动做界面交互验收。当前文件夹导航只覆盖收件箱，旧邮件按需加载、附件缓存上限、SMTP 不确定发送结果的服务端核对、复杂 MIME 字符集和同步限流仍需继续完善。静态预览见 [`design/onebox-preview.png`](design/onebox-preview.png)。

测试项目为 `OneBox.Tests`。在安装指定 SDK 后可运行 `dotnet test OneBox.Tests/OneBox.Tests.csproj --configuration Release`。最终 Release 产物应在界面验收后按明确构建指令生成。
